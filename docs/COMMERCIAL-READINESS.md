# 0.2.0-rc1 非支付商业化候选版

这是可在本机验收的候选版，不是已完成生产认证的企业级正式发布。没有支付功能，不开放真实资金写操作。

## 本次可验收范围

- Telegram 登录、选频道、原文收信、已有明确格式解析、同频道回复合并及唯一消息去重。
- 本地虚拟盘持续运行/重启恢复、止损与等份分批止盈、独立模拟 ID、结算报告。
- 实盘模拟页提供可编辑的新单定仓：固定 USDT 保证金、成交时权益百分比（最多 10%）、旧版风险/止损距离定仓。保证金乘杠杆得到名义金额；额外收取开仓手续费，固定/比例模式余额不足拒单，不悄悄缩量。保存不改变已有挂单/持仓的参数。旧账户保持原风险定仓，不自动切换策略。
- 信号追踪加入真实账号曲线区域。已实现实盘只读 API 的每日 UTC 最后一次 USDT 权益观测持久化，按 API 身份隔离，不混入模拟盘；这不是跟单净收益。跟单净收益仍为明确未接通状态，尚未完成真实成交/手续费/资金费率归因，不绘制虚假收益。
- 本地虚拟盘识别“稳健带成本损”“直接手动 TP1”“可留小仓做格局”（兼容繁体）。成本损含双边手续费，且只收紧原止损；手动 TP1 按原有等份第一档市价减仓；格局保留指令执行前剩余数量的 10%，目标为这部分开仓保证金的 500% 毛收益，保留原止损。组合 TP1+格局只执行一次尾仓减仓。
- 管理指令限定同频道唯一已开持仓，回复关系优先；无币种时必须有直接回复。歧义、过期、历史、编辑均不自动执行；消息及减仓阶段去重跨重启保存。空单杠杆不大于 5 时 500% 目标非正价格，整条指令拒绝，不先减仓。手续费不包含资金费率，保本触发不保证跳空行情下净收益为零。
- Bitget 经典 USDT 模拟盘自动开单、带止损和第一个止盈，提交不确定时停止重试。
- 公开 V2 ticker 推送（主流币种与虚拟盘活跃币种）、时间戳/正有限价格校验、乱序过滤、心跳重连、有效 REST 兜底。桌面推送每秒展示；交易处理收到的 ticker 更新，不宣称捕获交易所全部成交逐笔。
- 市价模拟单超过 120 秒未取得行情拒绝追单；含多个币种、多个入场/止损字段的歧义信号拒绝自动执行。
- 本地账号服务：注册七天试用、登录/退出、设备限制、管理员调整授权/禁用/解绑。密码 scrypt，服务端会话只保存哈希；桌面令牌通过 DPAPI 持久化。无需、也不会上传交易所密钥或 Telegram 会话。
- 诊断导出不含密钥/手机号/频道原文；SQLite 在线备份不含凭据，但包含私有频道消息和交易记录，请妥善保管。日志每份 5MB，保留三份轮转。
- 每版本首次升级前备份本地账本，原数据目录不迁出。开始菜单安装脚本保留旧程序备份，不清空用户数据。

## 本地账号服务验收

1. 运行 `scripts/start-account-service.ps1 -Bootstrap`，在本机终端交互输入管理员账号和至少 12 位密码；密码不出现在命令参数中。不要把密码发到聊天。
2. 运行 `scripts/start-account-service.ps1`，服务只监听 127.0.0.1:9000。打开该地址可登录管理员、开通授权、设置设备数量和禁用账户。
3. 桌面“连接管理 → 账号授权与系统维护”注册/登录试用账号。普通 EXE 默认本地验收模式，不强制授权。
4. 关闭普通实例，运行 `scripts/start-licensed-desktop.ps1` 验收强制授权：未登录、授权到期、账号禁用或服务器不可达时，拒绝新开单；已有持仓行情管理和结算仍可用。服务端状态最多缓存 30 秒，不支持离线许可证。
5. 管理员解绑设备会撤销该账号全部会话，用户须重新登录。

使用上述脚本时，服务数据库位于项目 `local-services/accounts/accounts.sqlite3`（已忽略 Git）；直接运行 Python 入口则默认位于 `%LOCALAPPDATA%/CopierControlPlane/accounts.sqlite3`。本地端口无 TLS，只供本机验收，未配置公网部署。生产部署需要 HTTPS、访问策略、持久化备份和告警。公开注册目前没有邮箱验证或反批量注册措施，不得直接当成公网付费试用服务。

## 安装/更新

`scripts/install-desktop.ps1` 把完整 release 文件夹复制到当前用户 Programs 目录，并添加开始菜单快捷方式。旧程序目录带时间戳保留；应用用户数据在原 `%LOCALAPPDATA%/CryptoSignalCopier` 中。不需要管理员权限。

该安装脚本尚未替代签名安装器。不要为运行脚本而永久降低系统执行策略；正式发行需签名安装包和可信更新发布链。本轮不会无签名下载并执行远程更新。

## 不可隐瞒的发布门槛

- 还需博主撤单、全平、加仓等其他原文样例及明确规则；当前仅支持上述已确认管理格式，不猜测其他指令，也不支持图片 OCR 自动开单。
- 上述管理指令只操作本地虚拟盘，尚未向 Bitget 交易所模拟盘发送减仓/改止损操作，界面明确提示。
- Bitget 模拟盘多档止盈仍只提交第一个目标；本地虚拟盘支持等份多档退出，不能把二者混称完全一致。
- 无用户真实账号的新消息→模拟盘成交/保护单回执连续验收证据；提交成功不代表成交。需真实频道和模拟账户长时间断线恢复测试。
- 模拟仍不含完整资金费率、订单簿滑点和交易所强平模型；关闭期间不伪造交易。
- 签名安装器、可信自动更新、公网部署、生产告警和安全审计尚未完成；缺少证书/发布服务时不能宣称可公开收费交付。

这些不是支付事项，仍属于正式商用前的未完成项。上述候选版用于逐项本地验收，不标记“除支付外全部完成”。
