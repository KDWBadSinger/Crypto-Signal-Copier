# 0.3.1 消息解析与重复信号修复

核对本机缓存原文后确认：

- ONE：7671/7672 均为 `#ONE 市價空 0.0031410`；7673/7674 分别回复各自开单，提供 `止盈：0.0029687-0.0027859-0.0025235`、`止損：0.0033155`。旧规则未支持繁体“損”。
- FORM：7681/7682 开多 0.3161；7683/7684 提供止盈 0.332/0.355/0.382、止損 0.305。同一繁体兼容缺陷。
- NIL：7677/7678 原文为入场 **0.9085**，7679/7680 止盈 **0.09474/0.10388**，低于多单入场价。这是参数矛盾，不能猜改为 0.09085；拒单保留，改为中文展示具体冲突价格。

更新启动后，在连接 Telegram 前用新版规则重解析本地缓存，修复开单及回复两端显示；不修改原文、不伪造历史成交、不补发订单。也可在消息页点击“重新解析缓存（不补单）”；在线时跳过最近 15 分钟的消息，避免干扰正在接收的开单回复。

重复内容有不同 Telegram ID，属于来源中不同消息记录。去重比较同频道的完整币种、方向、入场、止损和按顺序排列的全部止盈（含相关开单属性），只在原开单时间差不超过 120 秒时归并。开单时间窗口不因重复内容延长；不同频道、不同价格/保护参数、超过窗口的信号不合并。

去重映射持久保存，第二套消息不会触发第二次交易；管理回复关联到相同信号。界面默认折叠重复信号，可勾选显示原文；不删除消息。原始开单仍与自己的直接回复合并，不按币种或时间猜测回复关系。

新版 EXE：`release/local-0.3.1/CryptoSignalCopier/CryptoSignalCopier.exe`。保留整个目录，正常退出旧版本后打开新版。真实交易授权与用户数据沿用原本机目录；本次测试未替用户发送真实订单。
