# 0.4.1-local 动态默认杠杆

基于用户最后确认，取消旧 30x 及全局最高杠杆约束，仅改变新订单，不修改已有持仓。

- 币种杠杆清单有配置：采用配置值，最多交易所允许值。
- 没有配置：交易所实时最大杠杆乘 50%，向下取整数。例如 100x→50x、125x→62x、20x→10x。
- 读取限制失败、结果非法或候选低于交易所最低杠杆：拒单，不使用旧默认倍数兜底。
- UTA 在首次预览及正式提交前读取 V3 合约信息。设置杠杆后若元数据变化导致最终倍数不同，本次开仓停止，不按不一致参数下单。
- 本地模拟与经典交易所模拟自动跟单通过公开合约信息采用同一候选计算。各笔杠杆在入账时固定。
- 保证金默认 6%、单笔硬上限 7%、默认最多 5 仓/硬上限 6 仓不变。杠杆提高会放大名义敞口，临时止损到入场价的距离更小。

包含 0.4.0 的即时市价开仓、临时保护、5 分钟等待期限及三档 40%/40%/20% 止盈规则。旧参数 max_leverage/default_leverage 为读取旧设置而保留，不再作为自动执行上限。
