# UTA 实盘验收资金约束（2026-09-22）

用户已确认以下约束；修改普通配置不得绕过硬上限。

| 参数 | 默认值 | 硬上限 |
| --- | --- | --- |
| 初始保证金占下单时实时 USDT 净值 | 6% | 7% |
| 未平仓仓位数 | 5 | 6 |
| 杠杆 | 10 倍（保守初始值，可配置） | 30 倍 |
| 保证金模式 | 全仓 crossed | 不自动切换账户持仓模式 |

用户同时提到“最多 5 个”和“6 个硬上限”，因此按默认 5、配置最多 6 实现。

- 保证金 = 下单前重新读取的实时净值 × 配置比例；名义金额还需乘实际杠杆。
- 实际杠杆不超过用户配置、交易所币种上限、30 倍三者最小值。
- 数量按交易所步长向下取整。不满足最小下单量或全部止盈分档要求时拒绝，不扩大金额凑单。
- 不因亏损自动加仓，不摊平，不使用马丁格尔；同币种现有持仓或挂单不混合接管。
- 并发校验包括账户其他持仓及本程序待确认开仓。
- 6%/7% 是初始保证金比例，不是全仓模式下的最大亏损比例。
- API 超时不等于下单失败，持久化操作身份并核对回执，不盲目重发。
