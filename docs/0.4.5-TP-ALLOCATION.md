# 0.4.5 分批止盈比例

在币种杠杆页的默认杠杆比例下方，新增三个 0–100% 滑块。确认 TP1 解锁 TP2，确认 TP2 解锁 TP3；前一档修改后，后续重新确认。可选区间按剩余初始仓位计算，不可选区间置灰；合计 100% 且全部确认后才能保存。0% 禁用对应档位。

仅对新的本地模拟和 UTA 订单生效。每笔订单持久化开仓时的配置，后续保护回复、恢复流程及手动 TP1 使用该单快照。旧订单默认 40/40/20。不足三档仍使用原有等分规则。按数量步长向下取整，余数归最后一个非零档位；非零档位数量过小则拒绝而非扩大数量。交易所不发送零数量计划单。

验证：全量后端 208 项测试通过，随后新增回复关联与配置接口测试后，止盈专项 15 项测试通过。隔离浏览器验证 60/30/10、顺序解锁、上限拦截、灰色区间和保存后刷新保留；桌面版打包。无真实资金下单验收，未改动个人配置。
