# 0.4.6 手动平仓

- 模拟订单与持仓：每笔持仓可确认后平掉剩余数量，按公开行情计价并记手续费。全部平仓暂停新开仓、撤销本地待入场订单，不结束模拟 ID。行情不可用不伪造成交，保留原有保护。
- 信号追踪 / UTA 订单与保护状态：单笔或全部跟单仓位平仓，输入“确认实盘平仓”。仅受保护桌面窗口且已有管理授权可执行；不操作其他手动仓位或归属混合仓位。全部平仓先暂停新开仓。
- 批量操作先持久化所有退出意图，再逐笔执行。成交未知不盲目重复下单；确认部分成交且剩余归属核对后，按剩余数量继续（最多三次提交）。完全平仓后清理本程序保护单并归集成交收益。断网、交易所拒绝、混合持仓会显示待核对，不保证任何网络条件下立即成功。
- 保存配置或开启预览不会授权交易，测试未访问个人 API 或平掉真实仓位。
