# 0.4.7 独立实盘操作与订单日志

- 分支：`v0.4.7`，基于已同步的 `main`（0.4.6）。
- 导航顺序：市场行情、Telegram 消息、信号追踪、币种杠杆、实盘操作、跟单模拟、资金管理、链接管理。实盘为钱包图标，模拟为烧瓶图标，信号为记录图标。
- 实盘操作独立成页，沿用模拟页的开仓设置、四张账户指标卡、最近信号、博主策略、订单表和收益曲线布局。信号追踪保留原有列表、筛选及解析，移出实盘控制与真实账户权益观察。
- 实盘开仓保留权益比例、同时持仓上限及受保护桌面窗口的显式授权。实盘来源可从已监听频道中独立选择，按频道 ID 保存；取消选择只影响新开仓。保存设置不激活交易。
- 账户权益和 USDT 可用余额读取交易所；浮动盈亏明确标为交易所全账户 USD 浮盈。累计跟单收益为已核对成交的已实现盈亏减交易手续费，不含资金费、浮盈和充值提现；真实账户权益观察独立保留。
- 两套订单表均显示开仓时实际杠杆，多绿空红；增加操作后的详情栏，可展开开仓解析与逐笔操作日志。已确认平仓的操作栏显示灰色矩形“已平仓”。交易所未确认的退出仍显示待核对。
- 新订单保存开仓信号快照、原文、来源频道/消息 ID 和消息发送时间。模拟开仓、止损调整、止盈调整、减仓、平仓与撤销日志同账本事务写入；实盘日志记录状态转换、已核对保护调整及成交回执。管理消息、用户手动操作和行情触发分别标明依据，重复消息和重复核对不重复记录成交。
- 模拟日志随结算报告归档；旧订单显示现有信号解析及实际留存日志，并明确标注非开仓快照或历史缺失。历史消息缺少发送时间时显示“未记录”，不把接收时间冒充发送时间。
- 本版不扩大博主管理词汇；例如已有“带成本损”规则正常记录。“稳健可套保”等未支持词句不会因日志功能而新增自动交易行为。

验证：后端全套 227 项测试通过，包含新增 8 项证据持久化、幂等、事务回滚、旧单读取、信号时间及来源选择测试；前端生产构建与 4 项 Sites 测试通过。隔离合成预览检查实盘与模拟导航、杠杆颜色、已平仓标识、展开日志及真实资金激活禁用状态。预览 fixture 为 `backend/tests/preview_v047.py`，使用独立临时目录且禁止交易所请求；示例金额不是个人账户数据。

Windows 构建目录：`release/local-0.4.7/CryptoSignalCopier/`。运行时需保留整个目录，不能只移动 EXE。

最终构建启动检查：全新隔离数据目录下 EXE 退出码 0，健康检查通过、前端资源存在、未认证请求返回 403、公开行情返回 4 个币种。旧单兼容与显示调整后的相关回归测试 37 项通过。未使用个人交易凭据，未执行真实账户下单或平仓。
