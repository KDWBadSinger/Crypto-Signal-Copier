# 0.4.0-local 市价先开仓、回复补保护

适用：运行中的本地模拟、用户在桌面明确启用的 Bitget UTA USDT 永续实盘。保存 API 不等于启用交易。经典 V2 交易所模拟盘不执行缺少完整保护的开仓意图。

- 同频道实时“市价多/市價多、市价空/市價空”通过唯一币种、方向、价格校验后执行；历史、编辑、过期消息不补单。
- 入场参考价允许乘/除 10、100、1000；仅接受与当前行情偏差 `abs(行情/纠正参考价 - 1) <= 10%` 的唯一候选。原文、候选和校验行情保留。只改参考价，不改博主 SL/TP；执行采用当时市价。
- 开单带交易所预设临时 SL，确认实际成交后按实际成交均价、数量、杠杆重新计算。预算为实际初始保证金，包含估算双边 taker 手续费；资金费、跳空、滑点、强平不包含在保证范围内。
- 5 分钟期限持久化；UTA 从提交前计时（保守），本地模拟从成交计时。收到有效完整同频道回复后更新原仓位。不按币种猜测回复关联。
- 未及时收到有效保护：在线监测时请求只减仓市价退出，持久化请求身份，丢回执后先查不重发。关闭应用或断网期间只能依赖已提交交易所 SL；恢复后核对并处理超时，不能保证离线时正好第 300 秒平仓。
- 三档 TP 按初始成交 40%/40%/20%。数量步长向下取整，尾差归最后一档。小于交易所最低数量/金额时拒绝不合规保护，保留临时 SL 和期限，不擅自扩大仓位。
- 120 秒内同频道重复开仓意图共用持久化订单身份；任一重复原消息收到的保护回复均指向该仓位。重复回复不会再次开仓。

测试使用隔离账本及假交易所；不等于已完成真实账户成交验收。全仓下“止损预算 10 USDT”不承诺最终损失最多 10 USDT。
