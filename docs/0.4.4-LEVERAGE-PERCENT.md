# 0.4.4 默认杠杆比例

币种杠杆页新增 0–100% 滑块，步进 1%。点击保存后持久化；升级默认沿用 50%。

未配置币种的新单杠杆为 floor(交易所实时最大杠杆 × 比例 / 100)。0% 拒绝未配置币种的新开仓；计算结果低于交易所最小杠杆时拒单，不向上凑整。单币种覆盖优先，仍受交易所限制。已有仓位不调整，保护管理不停止。

本地模拟、经典模拟盘自动执行及 UTA 自动执行共用此规则。没有自动启用交易，没有补下历史订单，没有修改用户现有账户设置。

验证：195 项后端测试通过；浏览器隔离环境验证 0%/100% 滑动和保存；Windows EXE 打包并进行隔离启动检查。未进行真实资金下单验收。
