# UTA 接入进展（尚非实盘成品）

用户确认统一账户。当前经典 V2 实盘禁用仍保留，未开放真实资金执行。

## 已实现并测试

- 连接管理提供只读 UTA 检查，读取 V3 settings/info，输出账户模式、持仓模式及最小权限检查，不返回 UID、IP 或密钥。
- V3 开单参数预览函数：USDT 永续在线状态、真实 quantityMultiplier/priceMultiplier、最小名义金额、最大市价数量、杠杆上限、2% 追单限制与止损方向校验。单向/双向参数分别处理，clientOid 按账户与信号隔离。
- 多档止盈明确标为需要独立保护计划，不能把第一个 TP 冒充全部分批止盈。
- 所有写请求的网络/非 JSON/5xx 结果及 40010、40725、45001 返回进入不确定状态，不按明确拒绝处理或盲目重试。
- 新增 12 项 UTA 测试；全部后端共 106 项通过。实际公开 V3 BTC 合约规格已只读查询；没有向个人账户发送订单。

## 未完成，禁止当作商用实盘交付

- UTA 写入执行编排、保护单创建/修改/数量同步、分批成交处理、博主管理指令映射。
- 持久化订单生命周期与重启核对、撤单/平仓紧急控制、账户级额度与亏损限制。
- 按真实开平仓成交及费用生成跟单净收益；实际用户账户的小额授权验收。

本机默认桌面数据目录只读检查返回缺少完整 Bitget API 配置。需用户在本机新版连接管理自行保存并检查；不要在聊天提供凭据。只读检查通过不代表上述功能已经实现。
