# 0.4.8 第一版：入场质量与仓位容量

版本：`0.4.8-alpha.1`。仅在 `0.4.8` 分支试验，不合并 main。

## 稳定版与试验版

- main 已包含 v0.4.7（PR #4，合并提交 `923b92c`）；日常程序继续使用 0.4.7。
- 独立试验包：`release/preview-0.4.8/CryptoSignalCopier/CryptoSignalCopier.exe`，需要保留同目录 `_internal`。
- 试验版默认数据目录：`%LOCALAPPDATA%/CryptoSignalCopier-0.4.8-preview`。不自动复制稳定版密钥、授权、数据库或启用状态；不要用 `--data-dir` 指向正在使用的稳定版目录。
- 没有安装或替换稳定版，没有启用真实资金交易。运行源码属于 0.4.8；日常使用应打开现有 0.4.7 桌面包。

## 这版采取的方式

深度足够、价格合适就按原计划快速跟单；偏薄、拥挤时缩单和降低杠杆，严重追价或无法核验当前数据时跳过。不是把所有币都降为低杠杆，也不是通过放大亏损上限承诺“快速赚钱”。

实盘操作和跟单模拟各有一个“入场质量与仓位容量”面板，参数独立保存。运行方式：

- **执行**：按规则缩单、降杠杆或跳过；实盘新开仓用带价格边界的 IOC，未成交部分取消，不循环追价补单。
- **仅观察**：记录建议，但不改变原有开仓数量、杠杆和订单类型。
- **关闭**：沿用旧开仓流程，不请求新增盘口检查。

这些开关只影响新开仓，不停止已有仓位的止盈、止损、手动平仓和故障恢复。保存入场规则不等于启用实盘。

## 初始参数（可调，不是经过收益优化的最佳值）

| 项目 | 初始值 | 含义 |
| --- | --- | --- |
| 单币仓位金额上限 | 20,000 USDT | 杠杆后总持仓，不是保证金；实际额度还受下列条件约束 |
| 开仓价格容忍 | 0.8% | 相对当前最优对手价的 IOC 边界，不是保证成交价 |
| 盘口参与比例 | 10% | 只使用可见进场、退出深度的一部分 |
| 分钟成交额参与比例 | 5% | 最近完整一分钟与最近五根完整分钟线均值取小 |
| 压力退出深度 | 当前中间价 ±2%，保留 50% 挂单 | 为撤单留余量，只是当前快照情景 |
| 偏薄/拥挤时杠杆上限 | 10x | 不高于原计划杠杆；正常深度保留原币种设置 |
| 单笔压力亏损预算 | 权益 3% | 用止损距离、退出缓冲和手续费估算仓位，不是实际亏损保证 |
| 追价 | 同向超过 2% 减半，超过 5% 跳过 | 多单看上涨、空单看下跌，不因价格变得更有利而误判追价 |
| 喊单前异动 | 前五根完整分钟线同向超过 6% 减半，超过 15% 跳过 | 必须具有可核验的原消息发送时间 |
| 买卖价差 | 超过 0.8% 跳过 | 价差超过上限一半也视为偏薄 |

允许仓位取原计划、金额上限、进场容量、压力退出容量、成交额容量、杠杆调整额度、压力亏损预算中的较小值，再按交易所数量步长向下取整。拥挤时额外受原计划一半限制。模拟中已有同币仓位占用容量；实盘沿用已有同币仓位/挂单不混仓的规则。

例如当前观察到的压力退出深度为 40,000 USDT，参与比例 10%、保留挂单 50%，这一项给出的上限就是 2,000 USDT；其他限制可能进一步减小它。它不是“这个币永久只能下 2,000”，也不是“保证安全”。

没有接入市值排名，也不将盘口深度误当作市值。小市值是风险提示，具体交易所合约的可成交容量才直接约束本程序的订单。

## 下单与恢复细节

- 公开盘口和分钟线并行读取，单次检查有超时；盘口超过 3 秒、双边缺失/交叉、无效数据或最近五根完整分钟线缺失时，不用旧数据猜容量。
- 忽略尚未收完的分钟线；没有原消息发送时间或前序数据时，前置异动显示“未知”，不伪造结果，也不单凭未知封禁博主。
- 实盘在设置杠杆前评估，设置后重新读取权益和盘口；第二次不得扩大原计划。最终发送前再检查盘口时效，包括等待写请求队列之后。
- IOC 只控制新开仓价格。部分成交按交易所确认数量建保护，不把委托数量当作成交数量。如果部分成交量不足以完成原定分档，先核对止损，再请求只减仓退出，意图持久化并可恢复。
- 保留 v0.4.7 的全仓模式，没有暗中切换逐仓。全仓风险仍然存在，保证金不等于最大亏损。
- 模拟在收到新信号时保存规则，实盘在开始执行时保存规则；中途调参数不会改写该单策略。模拟老订单按原规则延续。
- 每笔保存原计划/调整后名义金额、杠杆、盘口时间、估算滑点、限制原因和规则快照。被跳过的信号也能在“最近入场决策”查到；已成交订单详情保留同一依据。
- 模拟和实盘自动跟单并行调度，模拟的新增检查不会阻塞实盘入场；模拟先处理已有持仓退出，再检查新入场。

## 博主跟随质量

分别统计实盘和模拟最近 1,000 条受评估信号：缩单/跳过数量、可核验前置异动、实际入场相对参考价偏离、已平仓归属收益，以及实际观察到的原信号编辑/删除。删除通知只有明确频道和消息 ID 才记录，不猜跨频道关联，不触发交易。

至少 20 笔已平仓样本才显示质量分：`50 + 平均净仓位收益率（百分数）× 10`，截在 0–100。净收益扣交易手续费，暂不含资金费。样本不足明确提示；跳过的信号不虚构收益，历史改文/删文不倒填。当前版本不依评分自动禁用博主。

## 边界与后续

本版不保证盈利，不识别“谁在盯账户”，不证明老鼠仓，也不能避免操纵或插针。盘口可撤走、成交量可能失真；当前退出深度不代表未来止损时能成交。既有市价退出不受入场价格容忍限制，以免新过滤器阻止减仓。

尚未实现：逐仓切换、市值/持币集中度数据源、资金费完整归因、平仓前异动评分、多时点深度稳定性、拆单调度、多个币同时崩跌的组合压力预算。不要把这些视为已具备。模拟只是快照估算，不复现真实撮合、撤单竞争、强平和完整退出滑点。

下一轮应先比较“仅观察”的建议与真实可复制收益，再调整参数；本次未做真实账户下单验收。
