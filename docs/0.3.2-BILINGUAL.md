# 0.3.2 简繁混合识别

开单、回复合并、交易参数校验、重复信号识别和持仓管理共用同一文字标准化入口，界面保留原文，不改价格小数位。

已覆盖既有句式中的市價/市价、入場價/入场价、進場/进场、多單/多单、空單/空单、買入/买入、賣出/卖出、止損/止损、風險/风险、倉位/仓位，以及穩健帶成本損/稳健带成本损、直接手動 TP1/直接手动 TP1、可留小倉做格局/可留小仓做格局。可简繁混用，支持全角字母数字和常见零宽格式字符。

否定与条件保护同样兼容，例如“暫不直接手動 TP1”不可自动执行。未知语义或未明确数量的“减仓”等新指令不会因简繁兼容而获得自动执行权限。

更新程序：`release/local-0.3.2/CryptoSignalCopier/CryptoSignalCopier.exe`，需保留整个目录。正常退出旧版后打开；既有历史重新解析只更新展示，不补单。现有实盘启用状态及风险参数沿用本地配置。
